# AT_update_team_member

1. 从明确的角色名或当前角色目录确定对象。若仍有多个可能对象，列出已登记角色请用户选定。使用共用入口 `python -X utf8 "<本技能目录>/../at-init-team/scripts/at.py" update-member --root "<项目或角色目录>" --input "<UTF-8 JSON 文件>"`，先传 `{"role":"角色名"}` 取得当前正文、路径和 SHA-256。
2. 基于原文修改用户指定的段落。保留文件标题、未涉及的措辞、用户添加的章节和原换行。明确的增删改直接执行；只有目标、内容或与原职责的冲突尚需裁决时，才就该项提问。若请求涉及更换角色身份或调整任务分派，先说明其与修改档案的区别。
3. 再次调用同一入口，传入 `role`、修改后的完整 `content` 和上一步的 `expected_sha256`。JSON 输入用文件 API 保存到项目外。并发冲突时重新读取，在最新正文上重做局部修改；提交失败且正文已写入时可用原输入重试。
4. 用改前、改后原句或简短差异说明具体修改，给出角色、档案路径和返回的角色仓库提交号。内容已经符合要求时说明已符合。
