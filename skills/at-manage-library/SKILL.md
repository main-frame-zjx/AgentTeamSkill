# AT_manage_library

为人类初学者写简洁的学习笔记。先用一个具体问题建立直觉，再讲项目实际采用的设计、取舍和适用边界。开工查资料时，用 `library-index` 搜个人库，按命中的角色和路径用 `library-read` 阅读原文。

1. 需求验收归档后按稳定需求 ID 取全量候选，阶段收口时按版本查。用户直接指定主题时，从核验过的材料开始。
2. 入库前问三件事：这是否是已落地的完整系统设计或可复用方案？未参与开发的初学者能从中学会哪项设计思路或避坑方法？用 `library-index` 的 `scope: project` 查重后，是否应该更新已有笔记？跨角色撞题时先与原作者协调。
3. 日常任务流水、单次小 Bug 或样式微调、未定型的会议脑暴草稿、临时阻塞与待办一律不入库。已有候选用 `memory-patch` 登记放弃理由，有学习价值但缺证据的标记待补。
4. 用 `library-upsert` 写入个人库并关联来源候选。「系统设计」讲结构和取舍，「可复用方案」给出可验证的步骤。引用实际源码、配置、素材或验收记录，核对重名提示与待重试项。

CLI 入口位于本技能的 `../at-init-team/scripts/at.py`。笔记字段、候选评估及导航修复见[工作记忆与个人库接口](../at-init-team/references/memory-library.md)。
