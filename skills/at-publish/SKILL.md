# AT_publish

首次正式发布某版本的程序包或用户指南时，脚本保存各角色当时的提交、建立 `memory/vX.Y` 标签并返回库巡检结果。首次封版后按角色和发布版本调用 `$at-manage-library`，评估该版本尚待处理的候选；用户明确指定阶段收口时也可这样评估。检查 `pending_memory`、`memory_warnings` 与 `library_health` 并分别处理。修复标签时用相同发布请求重试，已有修订和角色快照可直接复用。

1. **先核对当前会话的执行角色。** 沿用会话已确定的角色，从实际工作目录读取 `AT.json`。仅已登记的“项目负责人”和用户明确授权、已列入 `release_managers` 的管理角色可以执行。角色不符时立即停止，告知“当前角色〈角色名〉无项目发布权限，请切换到项目负责人的 AI 会话执行”，并列出本项目可发布角色。不要通过改目录、改 `--root`、代传他人的 `actor` 或临时给自己授权继续。项目根会话未绑定角色时，请用户确认本次使用哪位已登记管理角色，确认后在本次发布调用中传 `actor` 和 `actor_confirmed:true`。同一操作的检查和重试沿用这次确认。读取执行人的 `Agent.md` 和 `memory-read` 交接记录，选取用户指定版本或项目当前版本。管理岗位登记见[发布接口](references/release.md)。
2. **选择项目级交付类型。** 用选择框列出 **① Windows 可执行程序包、② 面向用户的项目介绍与使用指南、③ 面向甲方的项目总览**。缺少选择框时列出三项并等候回复。用户已选定时直接采用。每次按一个类别交付，公共 `publish/` 的三个子目录分别为 `bin/`、`user/`、`dev/`。角色自己的送验材料、试玩记录与阶段总结放入其 `report/`。
3. 用 `release-check` 传入发布类型 `kind` 和目标版本。**若同类同版本已有成果**，先告诉用户最近的修订号、时间和入口，给出“使用已有成果”和“再生成一个修订版”两个选项，等用户选择后再继续。沿用时调用 `release` 的 `reuse` 操作。新修订引用用户看到的修订号，目录独立编号为 `r1`、`r2` 等。新请求使用新的稳定 `request_id`，恢复中断用原编号和类别。
4. 按下表准备与核实交付物。程序包和用户指南首次正式发布该版本时，核对全部目标版本需求均已验收归档、自上次正式发布新增验收、至少一项真实交付文件或 Git 提交。读取检查返回的具体阻塞。另一类别及同版修订可复用已登记的版本验收快照。甲方总览从当时的需求、验收记录和实际成果取材，迭代中即可生成。
5. 调用 `release`，从返回的实际入口验证交付。HTML 在离线环境打开，检查图片、导航和正文；程序包返回主程序入口和需要完整复制的修订目录，并报告实测 Windows 版本、架构、核心功能及已知限制。历史修订各自可独立使用。

| 用户选择 | 准备与验证 | 发布入口示例 |
|---|---|---|
| ① Windows 程序包 · `bin` | 核对可执行文件的构建记录、版本和目标架构。优先复用匹配的发行成品，缺少时读取项目的构建脚本、说明及锁定依赖，在对应已验收代码版本上执行项目已有的发行构建。将主程序、需要的 DLL、插件、运行库和资源整理成完整发行目录，保留相对路径。用 `verify-bin` 在项目外的新目录及精简环境中实际启动并验证一项核心功能。自动化或图形程序的操作见接口文档。修复依赖后重新验证。 | `publish/bin/v1.0/r1/<程序名>.exe` |
| ② 项目介绍与使用指南 · `user` | 用首次使用者的语言写明用途、如何取得并启动、如何完成一个典型操作及已知限制。优先附实际界面、操作截图或成果样例，给出能解释画面的图注。 | `publish/user/v1.0/r1/index.html`，同级 `assets/` |
| ③ 甲方项目总览 · `dev` | 写明截至本次汇报的整体情况、关键进展、当前阻塞、待甲方决定的事项与下一步方向。按真实记录区分进行中、待验收和已归档。脚本生成进度图，可配实际成果图。 | `publish/dev/v1.0/r1/index.html`，同级 `assets/` |

共用入口为本技能目录的 `../at-init-team/scripts/at.py`。解析为绝对路径后运行 `python -X utf8 "<at.py>" <命令> --root "<实际工作目录>" --input "<UTF-8 JSON 文件>"`。字段和完整请求示例见[发布接口](references/release.md)。
