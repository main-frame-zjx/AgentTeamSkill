# 2026-11-27 · 角色通讯、工作记忆与项目版本

本次迭代将 AgentTeam 扩展到 16 项技能。角色可以在项目内送验、打回和请求协作，并在下一次开工时一起查看待办、需求和交接记忆。

## 角色通讯与验收

- 通讯记录随项目保存在本地。需求第一次发信时建群，每条消息记录发送角色和模型，每位接收者独立处理。验收人可以改派，送验和打回可以抄送，验收通过只需核销原提醒。
- 新增 `$at-receive-message` 和 `$at-reply-message`。`$at-work` 开工时收齐分页待办，按需求列清单，收尾核对流转事件、统一结算并更新记忆。等待澄清的事项会保留在下次收件箱。
- Agent 可通过本机 MCP `agent-team-chat` 或 CLI 操作。重试使用幂等键，跨群结算通过事务日志恢复。用户可以双击网页或打开 Windows 桌面入口，按角色查看待办、群历史和引用文件。[通讯协议](../../skills/at-receive-message/references/protocol.md) · [通讯看板](../../chat-visual/index.html)

## 工作记忆与个人学习库

- 每个角色的 `Memory.md` 用六个栏目记录交接现场，正文最多 6,656 个 UTF-8 字节。开工时可同时读取当前焦点、活跃需求、风险及工作树状态。
- 角色可以在需求备注或送验时登记学习候选。验收或阶段收口后，有证据的设计和可复用方案可整理为 Obsidian 笔记，可在个人库或整个项目中检索笔记，按需求或版本筛选候选。首次正式发布程序包或用户指南时，保存角色记忆快照。[记忆与学习库接口](../../skills/at-init-team/references/memory-library.md)

## 项目格式与升级

- 项目工具和看板现在读取 `agent-team/v3`。新项目默认从 `v1.0` 开始，建单时绑定目标版本，看板可按当前版本或指定版本筛选。现有 v2 项目需要单独迁移，本次没有提供自动迁移工具。
- 已有 v3 项目即使还没有通讯目录，也能查看开工上下文和空收件箱。首次有效写入时创建通讯区。
- Windows 现在提供项目看板、技能手册、角色通讯和停止服务四个桌面入口。更新技能时在源码根目录运行 `python install.py`，新会话即可发现新增技能。只安装技能可使用 `--no-mcp`。[安装与验证说明](../../README.md)
